# Installing BepInEx

BepInEx is the modding framework required to run ScarletCore and any other V Rising server mod.

## Download

Download the latest version from Thunderstore:

**[BepInExPack V Rising — Thunderstore](https://thunderstore.io/c/v-rising/p/BepInEx/BepInExPack_V_Rising/)**

Click **Manual Download** to get the `.zip` file.

---

## Installation

1. Extract the downloaded `.zip` into a temporary folder — **not** into the game folder directly.
2. Open the extracted folder and go inside `BepInExPack_V_Rising/`.
3. Move **all contents** of that folder into your V Rising Dedicated Server folder:
   ```
   <Steam>\steamapps\common\VRisingDedicatedServer\
   ```
4. Start the server.

If the installation was successful, a BepInEx console window will open alongside the server.
